    • quick and easy to build

      If you can code a few nested <ul>...<ul> lists, you got this!

    • the user experience

      • intuitive content scaling

        In a multi-level list, the most important information is generally at the top level, while deeply nested information tends to be less important or not necessarily of interest.

        bubble-tree scales down nested information until the user shows interest by clicking into it.

      • navigating

        Touching or clicking a circle zooms in our out on the list so that the circle fills the viewport. This hides its parents and increases the size of its children.

        When zoomed in, a link for returning to the top appears in the top left. It disappears when touched.

        Offsite links are disabled when they are very small. They become active when the user zooms in close enough.

    • how it works

      bubble-tree styles every <li> tag as a "bubble" (a circle with a semitransparent background) and arranges the bubbles to show the data hierarchy.

      <li> elements are arranged vertically, as in a normal list. Nested <ul> lists are displayed to the right of their parent <li> elements. They add width, but not height, to their parents.

      • portrait

        Bubbles are arranged vertically like a normal list. This creates a list that is higher than it is wide, as long as there are at least two <li> elements in the top-level <ul> list.

        landscape

        When there is only one <li> element in the top-level <ul> list, the bubble-tree is wider than it is high, and dominated by one large circle on the left, which works well as a title page.

      • overall size

        When the page loads, the list is resized to fit the limiting viewport dimension.

      <ul id="bubbleTree">

      • follow best practice for nesting lists

        Place each child <ul>...</ul> element inside an <li>...</li> tag of the parent list. more info

      • use block elements inside <li> tag

        Text placed directly inside the <li> tag will exceed the boundary of the circle.

        To pad text so it fits in the bubble, place it inside a tag (such as <p>, <h1>, <h2>, etc.) that is a child of the <li> tag.

    • add the JS and CSS assets

      Add bubble-tree.css to the project. Assuming it's in a folder named "css" next to your html file, link to it from your html file with a tag like <link rel="stylesheet" href="css/bubble-tree.css"> inside the <head> section.

      Add bubble-tree.js to the project. Assuming it's in a folder named "js" next to your html file, place a tag like <script src="js/bubble-tree.js"></script> before the closing </body> tag.

    • use bubble-tree styling features

      • color theming

        bubble-tree uses the hsla color model.

        • random colors

          set randomBubbleColors = true in JavaScript before bubble-tree.js to randomly color the bubbles. The colors change every time the page loads. Bubbles with IDs are skipped, which prevents custom styling from being overridden.

        • primary and secondary colors

          if randomBubbleColors is false or not set, bubble-tree colors the bubbles using primary and secondary color variables defined near the top of bubble-tree.css.

          The top-of-page link uses the primary color.

        • color variables and default values

          --primary-hue: 20;
          --primary-saturation: 100%;
          --primary-lightness: 49%;
          --secondary-hue: 20;
          --secondary-saturation: 0%;
          --secondary-lightness: 30%;

      • fonts

        font size

        Set font size using --base-font-size near the top of bubble-tree.css. Use cqh units (not px, pt, em, or rem) so that the text scales with its <li> container. New to container queries?

        bulleted lists

        For a bulleted list having up to two levels, apply the provided bullet1 and bullet2 classes to <p> elements.

        bullet1

        bullet2

        • headings and accessibility

          Follow best practices and use headings to organize a document. Never use heading elements simply to apply a desired text size.

          bubble-tree looks good with a consistent heading size within each bubble, but don't use the same heading level throughout.

          <h2>, <h3>, <h4>, and <p.headingSize> all look alike. Use them to tell document readers how your information is organized (which may or may not match your bubbles). Use <p.subheadingSize> for secondary headings.

    • apply your own custom styling

      To customize an <li> element, give it an ID and reference it by ID in your CSS.

      • add a background image

        Setting a CSS <background-image> for an <li> element crops the image to a circle that completely fills the bubble. By default, the image is centered and scaled to fit the circle. Override this with custom CSS if that's not what you want.

      • positioning inside a bubble

        flexbox

        Each <li> element is, by default, a flexbox container. Its children (other than <ul>s) are arranged from top to bottom, vertically centered in the bubble, and padded left and right.

        absolute positioning

        <li> elements are absolutely positioned, so they support absolute positioning. Note that <li> elements are actually squares with rounded corners, so elements placed in the corners (e.g. top:0;left:0) will fall outside the circle bounds. Set overflow:hidden on a bubble to trim content along the edge of the circle.

    • caveats

      • <li> element can't contain plain text

        The text needs to go inside a child element such as p, h1, h2, etc. This is valid HTML. Text placed directly inside the <li> element will exceed the boundaries of its bubble. more about content placement

      • max 6 list items per parent

        If you need more than six <li> per <ul>, you can easily increase this limit by building out the CSS classes at the end of bubble-tree.css, but the bubbles will be very small relative to their parent.

      • doesn't play nicely with other lists

        bubble-tree can't contain a "vanilla" (unstyled) <ul> or <ol> list. You can style <p> tags to look like a list. more info

      • occupies entire viewport

        It is on the road map to make bubble-tree play well as part of a more complicated page layout.

      • distortion on extreme transforms

        Some aspects of an element's appearance, particularly text line spacing and circle shape, distort noticeably when bubbles are very deeply nested.

      • underlining text

        text-decoration:underline doesn't work in small bubbles because the underline doesn't scale along with the font size.
